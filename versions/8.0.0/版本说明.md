# BiliClip 喵贴 8.0.0 · 上传助手

持续更新同一文件，不增加版本号或新建版本文件夹。7.2.3、7.3.0 存档保持不变。

## 当前面板

顶部「一键执行」，下方按 B 站表单顺序显示标题、创作声明、分区、简介。

- 主声明使用独立浮层，选择后立即关闭浮层并应用；再次点击当前项也可重新应用。
- 「内容为自制：未经作者允许，禁止转载」置于声明下方，勾选立即添加，取消立即移除；仅更新授权，不改动主声明。
- 连续切换声明与勾选按顺序执行，避免忙碌时丢失最后一次操作。
- 转载稿件不能添加自制授权，按 B 站规则禁用对应勾选。
- 知识分区、标题抄录和简介第二行预设仍可由顶部一键执行。
- 设置自动保存，自动执行开关收在底部折叠区。
- 保留简介第三行及后续文字，不会自动投稿。

## 兼容处理

原生 DOM 查询上传页输入框；简介适配 Quill；知识分区模拟完整点击事件并等待选中确认。主声明操作 `.bcc-option`；授权单独操作 `.auth-content`，通过 `.option-text-selected` 读取真实状态。

语法及相关逻辑模拟回归检查通过，包括无主声明预设时取消授权、重复执行和授权与主声明并存。本次交互修改尚未安装到浏览器验证。

使用：将 biliclip-8.0.0.user.js 完整替换到油猴脚本，保存并刷新上传页。

## 本次修复与新增

- 视频详情页进入网页全屏或播放器全屏时，隐藏喵贴整组复制控件；退出全屏自动恢复。监听 Fullscreen API、播放器 `data-screen` 和旧版播放器模式类名。
- 上传页左侧新增「喵贴 · 找视频」，右侧上传助手继续保留。左侧面板可收起，状态自动保存。
- 点击「刷新我的视频」读取创作中心已发布稿件，分页间隔 1.2 秒，最多读取最新 2000 条。按登录账号缓存，失败保留旧列表，不在每次打开上传页时自动请求。
- 支持按标题或 BV 本地搜索；「相关推荐」按当前投稿标题与自己稿件标题的词语匹配排序，无匹配时按最新稿件排序。推荐范围为自己的已发布视频。
- 每条视频支持「填入 BV + 标题」与「复制 BV + 标题」。前者要求先展开关联视频，复用原有字段识别与填充校验；后者复用原有配对剪贴板与粘贴流程。标题填入关联视频的「描述文案」，不替换当前投稿标题。
- 面板搜索框内普通粘贴不触发配对填充。缓存采用脚本管理器存储，不保存 Cookie。

参考 [FindMyBV 的工作思路](https://github.com/Leochens/FindMyBV/blob/main/src/bookmarklet/bilibili-video-picker.js)：创作中心只读稿件接口、分页、缓存及本地过滤。新增界面和配对填充由喵贴自行实现。

验证：`node --check versions/8.0.0/biliclip-8.0.0.user.js` 与 `node tests/8.0.0-regression.cjs` 通过，覆盖稿件归一化、去重、推荐排序、全屏隐藏/恢复、双字段填充及字段未展开。尚未在登录后的 B 站页面实测接口和界面。

## 面板位置与拖动调整

- 两个面板改用页面坐标定位，随页面滚动移出/进入视野，不再固定覆盖导航或投稿操作。
- 左侧面板默认从导航右侧开始放置（至少距页面左侧 208px），展开和收起使用同一位置；右侧面板默认置于页面右侧。
- 展开时拖动面板顶部标题栏，收起时拖动标签，均可移动。拖动超过 5px 才视为拖拽，拖完收起标签不会误触展开。
- 左右面板分别保存拖动位置；展开、收起和窗口缩放时校正横向边界。上传助手的声明浮层在拖动时关闭，避免浮层停留在旧位置。
- 回归检查新增默认导航偏移、页面滚动坐标、标题栏/标签拖动、拖后点击抑制和位置记忆。尚未在真实投稿页进行视觉验证。

## 面板交互修订（以本节为准）

- 两个面板使用视窗固定坐标，默认在两侧垂直居中，滚动页面时保持位置。每次进入页面默认展开；保留标题栏和收起标签拖动，记忆拖动位置。旧版页面坐标不迁移，避免面板落到错误位置。
- 上传初始页（尚未出现标题编辑框）隐藏两个面板，继续编辑、放弃和上传入口保持可用；出现编辑表单后自动显示。检测到确认弹窗或面板与关键按钮重叠时临时隐藏，条件解除后恢复。面板层级降低到普通页面浮层之下。
- 找视频结果展示封面、发布日期、带播放图标的播放量以及视频时长。旧缓存没有这些数据时需刷新稿件列表。
- 右侧新增「自动展开页面『更多设置』」复选框，默认关闭并保存选择。开启后尝试展开一次，识别已展开状态时不点击，避免轮询重复开合。
- 稿件管理相关页面也显示找视频面板；点击关联视频或添加关联视频、或检测到关联视频输入框新出现时，自动展开已收起的找视频面板。关联字段识别兼容上传页微应用和开放的 Shadow DOM。
- 语法和模拟回归通过，覆盖固定坐标、拖动、媒体元数据、稿件管理路由、更多设置一次展开、上传初始页隐藏、编辑恢复、组件触发展开及关键按钮避让。尚未在登录后的真实 B 站页面视觉验证；页面 DOM 变更可能需要进一步适配。

## 置顶、缩放与跨域填充修复

- 上传助手与找视频面板恢复高层级置顶；上传初始页及关键操作避让仍保留。展开面板可从右下角用鼠标调整宽高，记忆尺寸。
- 面板顶部标题栏固定在内部滚动区顶部；面板坐标不会因视频列表刷新、内容高度变化或轮询而重新居中。收起标签也保持视窗坐标。
- 视频列表改为左侧 76×48 小封面，右侧紧凑显示标题、BV、发布日期、播放量和操作按钮。
- 在真实投稿页核对到「更多设置」标签附带「含声明与权益、视频元素、互动管理等」说明，旧版完整匹配漏掉该入口。本次放宽标签匹配，并在勾选时立即执行，也加入一键执行入口。
- 在真实页面核对到个性化卡片位于 `www.bilibili.com/web/player/index.html` 跨域 iframe。新增父页面与编辑器内脚本的消息通道，检查来源、目标窗口和请求 ID；编辑器内使用实际 placeholder 定位 BV 与描述框，填写后验证再回传结果。
- 填入按钮增加面板内结果反馈。组件输入框出现时通过消息自动展开父页面找视频面板。
- 语法和模拟回归通过，包括带说明的更多设置标签、缩放启用与跨框架回执；尚未把本次脚本安装到浏览器完成端到端验证。更新后必须刷新完整投稿页，让父页面和 iframe 都载入新代码；打开个性化卡片 → 关联视频 → 添加关联视频后再点填入。不会自动提交组件或投稿。

## 紧凑列表、浮层吸附与保存设置

- 列表操作改为一行短按钮「填入」「复制」，悬停说明仍为 BV + 标题；按钮行使用整行空间，减少小封面下的留白。
- 个性化卡片编辑器显示时，找视频面板吸附到编辑区左侧；上传助手降至编辑器浮层下面，关闭编辑器后恢复原来的位置和层级。
- 点击关联视频时尝试展开已有卡片设置，尚无卡片时触发添加；若 B 站提示时间段冲突，不会删除已有卡片。填入按钮阻止外部点击冒泡与鼠标按下导致的焦点切换，填入完成后再检查展开状态，不自动提交或收起组件。
- 更多设置复选框支持勾选展开、取消收起，一键执行同样应用保存的展开/收起选择。
- 更多设置上方新增「增加商业推广信息」，对应 B 站实际 `label.bcc-checkbox`。勾选/取消立即同步并保存，一键执行也会恢复所保存的商业推广状态。
- 标题抄录、分区、声明、自制授权、简介预设、自动执行、更多设置和商业推广选项均继续使用脚本管理器持久保存。新页默认读取预设，点击一键执行后应用；商业推广不会在进入新页时擅自改变。
- 语法与回归通过，新增覆盖更多设置开/关、商业推广勾选/取消/重复执行、吸附及浮层关闭后恢复。本次在真实页面核对了商业推广控件，尚未安装新版完成视觉与端到端验收。

## 面板尺寸与自适应重构

- 面板改名为「喵贴 · 视频素材库」「喵贴 · 投稿工作台」，收起标签同步更新。
- 使用独立的四边、四角缩放手柄，支持八个方向调整尺寸；上边和左边缩放时同步改变坐标，限制最小尺寸与视窗边界。尺寸使用新的 v2 存储键，避免旧尺寸破坏首次适配。
- 首次按浏览器宽高计算尺寸，左右面板分别占约 72% / 68% 可用视窗高度。窄视窗按可用宽度分配左右空间，窗口缩小时限制尺寸并保持控件可见。
- 顶部栏固定，内容区域独立滚动；素材库放宽后自动按列排布，工作台根据容器宽度调整字段列宽与留白，输入区随面板拉伸。
- 素材列表去掉视频时长，保留发布日期和播放量；小封面、标题与 BV 紧凑排布，右侧纵向放置「填入」「复制」两个轻量按钮。
- 个性化设置打开时按实际浮窗外框定位，素材库紧贴左边缘，不留原来的 8px 间隙；左侧空间足够时贴外侧，空间不足时贴左侧内边缘。缩放和拖动期间保持吸附；工作台仍位于个性化设置浮层下方。
- 语法、原有回归和八方向缩放几何检查通过。在本地模拟页使用浏览器检查了窄视窗初始尺寸、双面板布局与示例素材列表。尚未安装到真实 B 站完成吸附和缩放交互的端到端验证。

## 显示范围与外侧吸附修正（以本节为准）

- 视频面板统一命名为「喵贴 · 关联视频库」。普通投稿表单和上传初始页不显示此面板；投稿页仅在个性化卡片编辑器显示时创建，关闭编辑器后移除。稿件管理页仍独立显示并允许拖动。
- 工作台默认宽度不再按屏幕比例放大，默认上限 280px、高度上限 460px；默认位置参考真实标题/简介输入区最右边界，左边缘位于表单右侧 12px，宽度不能超过剩余空间。空间不足时默认收成标签，避免遮挡输入区。用户拖动、缩放或主动展开后不再强制套用默认避让。
- 位置与尺寸改用 v3 键，隔离旧版过大的默认面板记录；业务预设不变。
- 关联视频库的右边缘严格等于个性化卡片浮窗左边缘。移除“空间不足贴内侧”的回退；空间不足时临时调整浮窗宽度和水平位置，为外侧视频库预留空间，关闭后恢复原始样式。
- 保留八方向缩放和稿件管理页的鼠标拖动。语法和模拟回归通过，新增覆盖普通投稿页隐藏、卡片/稿件管理页显示、表单边界默认尺寸、手动调整不覆盖、外侧精确吸附及浮窗样式恢复。尚未安装本次脚本到真实 B 站做视觉验收。
