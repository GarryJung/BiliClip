# BiliClip 喵贴 8.0.1 · 全功能引导教程

基于 8.0.0 新增独立版本，保留旧版与原有业务设置。

安装本目录脚本并刷新完整 B 站页面。首次顶层页面自动开启实操引导；暂存退出后不再自动弹出，可手动续接。可从脚本菜单、投稿工作台或关联视频库的「使用教程」随时重看。支持 26 步聚光实操引导：黑灰遮罩仅留出当前控件，简短气泡随按钮移动并避让视窗边缘。点击、输入停顿、刷新或执行完成后自动切步；开关类可保持原样点「知道了」。找不到目标时允许操作页面，不阻挡导航。保留跳过、退出和续接，移除教程中的长文、章节目录与重复下一步操作。教程不代点业务控件。

## 开始前：安装与更新

1. 在 Tampermonkey 或 Violentmonkey 中打开 8.0.1 脚本，确认安装或替换旧代码并保存；扩展版与脚本版只启用一种，避免重复按钮。

2. 更新后刷新整个 B 站页面，包含创作中心和个性化卡片编辑器；仅关闭重开组件可能仍使用旧代码。

3. 本教程只讲解，不会替你修改表单。使用“上一步 / 下一步”顺序阅读，也可在目录中跳转。关闭后可从两侧面板的“使用教程”或脚本管理器菜单重新打开。

## 视频卡片与详情页：复制信息

1. 在 B 站视频列表把鼠标停在视频封面上，点击“复制 BV + 标题”。如果卡片没有标题，脚本会尝试向 B 站接口查询。

2. 打开视频详情页，可分别使用“复制 BV”“复制标题”或“复制 BV + 标题”。需要配对填充时选择组合复制。

3. 播放器进入网页全屏或浏览器播放器全屏后，复制控件会隐藏；退出后恢复。找不到按钮时先退出全屏并刷新页面。

## 粘贴：一次填两框与交替粘贴

1. 先组合复制，再进入创作中心打开“个性化卡片 → 关联视频 → 添加关联视频”，等待 BV / 链接和描述文案输入框出现。已有卡片可先展开设置。

2. 在任意一个关联输入框按 Ctrl+V（Mac 为 ⌘+V），或使用右键粘贴；喵贴把 BV 填入链接框、标题填入描述文案。检查两个字段后自行提交组件。

3. 在普通 B 站输入区，组合复制后按 BV → 标题顺序交替粘贴。只复制单项则按普通文本使用。

4. 中途复制其他文字后，实际剪贴板优先；想继续配对请重新组合复制。视频库搜索框中粘贴只用于搜索，不触发配对填充。

## 投稿工作台：显示位置与一键执行

1. 进入视频投稿编辑表单，填写当前视频标题。上传初始选择文件页不显示工作台；输入框出现后再找右侧“喵贴 · 投稿工作台”。

2. 依次确认标题抄录、创作声明、自制授权、知识分区、简介第二行、推广、更多设置，再点击“一键执行”。设置会自动保存，下次继续读取。

3. 一键执行会应用保存的更多设置开关和商业推广状态，再处理声明、分区、简介。勾选标题抄录时必须先有投稿标题。

4. 执行后阅读面板底部每一项的结果；后续步骤失败不代表前面的修改已回滚。核对 B 站表单后自行投稿，喵贴不会自动投稿。

## 标题与简介：哪些行会被替换

1. 勾选“抄录到简介第一行”，一键执行时使用当前投稿标题替换简介第一行；不勾选则保留原第一行。

2. 在“第二行引导话术”填写预设，例如“更多内容请查看我的主页”。有预设时一键执行会替换第二行；空预设不代表清空现有第二行。第三行及后续文字保留。

3. 脚本管理器菜单提供“上传简介设置”“标题填入简介第一行（含第二行预设）”“填入简介第二行预设”。后者仅替换第二行，前者按当前标题与预设处理。

4. 主动执行会覆盖对应行，建议先保存重要文案。简介与标题框未出现时，先进入完整投稿编辑页再操作。

## 创作声明与自制授权

1. 点击工作台“声明”打开选择浮层。主声明为单选：不设置主声明、内容无需标注、含AI生成内容、含虚构演绎内容、内容含营销信息、个人观点，仅供参考、内容为转载。请按稿件实际情况选择。

2. 选择后立即保存并尝试应用到 B 站，浮层关闭；再次点击当前项可重新应用。“不设置主声明”是预设留空，一键执行不会据此主动清除已有主声明。

3. “内容为自制：未经作者允许，禁止转载”为独立授权：勾选立即添加，取消立即移除，不改变主声明。内容为转载时不可添加该自制授权。

4. 连续切换会排队执行，请等面板提示完成，并核对 B 站原生选项是否一致。

## 分区、商业推广与更多设置

1. 勾选“知识”表示一键执行时选择知识分区；不勾选则跳过该步骤，不会恢复先前分区。是否自动选择由下方独立开关决定。

2. “增加商业推广信息”勾选或取消会立即同步 B 站对应选项并保存。一键执行也会应用保存的开关，包括取消状态；新页面不会仅因加载预设就修改推广选项。

3. “自动展开页面『更多设置』”勾选会立即尝试展开，取消会尝试收起；一键执行也应用此状态。找不到入口时请进入完整表单并查看状态提示。

## 自动执行：三个独立开关

1. 展开底部“自动执行设置”。“自动选择知识分区”默认开启，编辑页检测到可用控件后尝试选择知识；不需要时先关闭。它与一键执行的“知识”勾选分别控制自动和手动行为。

2. “自动选择预设声明”按保存的声明与授权设置尝试应用；开启前先核对预设适用于当前稿件。

3. “自动补充空白第二行”默认关闭；开启且存在预设后，仅补充空白第二行，每个简介框补一次，手动删除后不会持续反复补回。已有第二行不会被自动覆盖。

4. 自动模式不会自动投稿，也不会持续把标题抄录到简介第一行；完整处理仍可主动点击一键执行。

## 关联视频库：打开与读取自己的稿件

1. 投稿页只有打开个性化卡片编辑器时才显示“喵贴 · 关联视频库”，关闭编辑器后移除；稿件管理页独立显示。普通投稿表单没有该面板是正常行为。

2. 登录自己的 B 站账号，点击“刷新我的视频”开始读取已发布稿件。不会在每次打开页面时自动联网刷新；等待状态提示完成，读取间隔约 1.2 秒，最多获取最新 2000 条。

3. 列表按账号缓存于脚本管理器，不保存 Cookie；请求失败保留旧列表。切换账号后需在对应账号重新刷新，旧缓存的封面或播放量缺失也可通过刷新更新。

4. 每条展示封面、标题、BV、发布日期、播放量。搜索输入标题片段或 BV，在缓存中本地过滤，最多展示前 100 条；结果太多时缩小关键词范围。

## 关联视频库：推荐、填入和复制

1. 先填写当前投稿标题，再点击“相关推荐”：清空搜索词，按自己已发布稿件与当前标题的词语匹配排序；无匹配时按最新稿件排序，不是全站推荐。

2. 先在 B 站组件中展开关联视频两个输入框，再点击某条稿件的“填入”。BV 和该视频标题分别进入链接与描述文案，不替换当前投稿标题。查看视频库状态提示确认是否成功。

3. “复制”只组合复制该条 BV 与标题；到目标字段按粘贴即可。适合跨页使用。

4. 跨域卡片编辑器也可填入，但更新脚本后必须刷新整个投稿页。时间段冲突时先在 B 站处理已有卡片，喵贴不会删除它们，也不会自动提交或关闭组件。

1. 点击标题栏“−”收起，点击同名标签展开。每次进入页面默认展开，工作台右侧空间不足时可能先显示为标签。
