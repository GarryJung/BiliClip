# 喵贴 BiliClip 8.1.5

- 关联视频库的稿件行提供「填入」和粉红色「播放」。播放在新标签页打开，悬停在被截断的标题上可看全文。
- 视频卡片封面在「复制 BV + 标题」左侧增加蓝色「复制标题 + 链接」。
- 详情页的复制按钮嵌在播放器和视频操作栏之间，提供标题、BV、BV + 标题、链接、标题 + 链接五种复制方式。
- 「复制 BV + 标题」把完整的两行文本写入剪贴板。只有在创作中心关联视频的两个输入框之一粘贴时才按字段双填，其他位置走浏览器原生粘贴，移除交替粘贴。
- 详情页复制栏采用低对比文字按钮。标题、链接与 BV 在左，接着是 BV + 标题，最后是标题 + 链接。放大详情页按钮与图标。BV 和 BV + 标题的图标及反馈用粉红色，其余用蓝色。悬停、按下和反馈用底色区分。复制和关联填入的结果直接显示在原按钮上，反馈结束后恢复原文案。
- 关联视频库的「填入」「播放」统一用 14 px 白字。调整五个实操场景的引导气泡，关联列表为空时先引导刷新，填入成功后引导核对。
- 修复脚本在页面已加载时注入导致的启动中断。各组件独立初始化，单个组件失败时其他组件可继续加载。
- 复制引导先提示粉红色的 BV + 标题，再提示蓝色的标题 + 链接。标签预设引导气泡优先放在高亮区正上方或正下方。
