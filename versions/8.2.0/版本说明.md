# BiliClip 喵贴 8.2.0

- 依据设计 06、07 更新脚本 UI、提示与实操引导。
- 投稿助手分组为内容填写、投稿选项、自动执行与更多设置，执行入口改为“应用设置”。
- 统一复制按钮、标签预设、关联视频库和反馈的蓝粉色、小圆角与浅边框。
- 改善错误提示、长提示换行、键盘聚焦与减少动态效果支持。
- 保留原有设置存储和场景引导记录。

实际 B 站账号页面仍需安装后复核。

## 关联视频与实操引导补齐

- 视频库增加搜索标签、选中页签、合集路径、时长角标、加载状态和失败重试入口。
- 关联填入成功后显示自动消失的轻弹窗，不插入常驻核对框。
- 引导卡片加入品牌 Logo、场景进度和等待操作状态；保留操作成功后自动推进。
- 本地 Chromium 真实 DOM 检查：列表渲染、切换合集、缓存恢复、时长显示、填入反馈、提示关闭、引导 Logo 与等待状态。

## 使用反馈修正

- 蓝粉实色按钮使用白字。
- 移除关联编辑器核对框和视频库常驻成功提示，填入成功仅显示轻弹窗。
- 主页悬浮复制入口加入品牌说明，复制成功显示 Logo、勾选、短文案和关闭按钮。
- 引导增加页面标记与会话级去重，打开前记录，主动重开时清除；验证投稿引导仅一次，然后进入个性化卡片。
- Chromium 本地真实 DOM 18 项检查通过；另有引导顺序回归测试。

## 页面交互与控件位置修正

- 去掉封面复制操作下方的品牌说明条。
- 详情页所有复制按钮同样显示复制成功轻弹窗。
- “一键执行”恢复原名并放回投稿助手内容顶部。
- 删除所有标签按钮使用活动粉红色 #FF6699；预设标签名改为“喵贴·预设标签”，常规字重。
- 引导遮罩不拦截页面点击，最后一步不再吞掉原生导航/投稿事件。
- 详情页复制栏等待页面加载完成后再插入，减少初始渲染干扰；实际导航缺失仍需真实页面复核。

## 轻弹窗动效微调

- 移除自动消失提示的关闭按钮。
- 与操作按钮间隔 20px，顶部空间不足时转到下方并限制在视口内。
- 改为 160ms 淡入淡出及 4px 位移，移除缩放回弹；修复连续提示被上一次隐藏定时器提前关闭的问题。
- 视频库“填入”“播放”使用常规字重。

## 引导微动效

- 卡片轻移淡入，小猫首次探头。
- 高亮仅轻呼吸两次，成功后小猫点头并绘制勾选，停留 400ms 再推进。
- 步骤切换使用 240ms 位置过渡，滚动和缩放时直接追踪目标。
- 减少动态效果模式禁用探头、呼吸、点头和位置动画，仅保留淡入；关闭引导清理动画与监听。

## 引导表现与个性化卡片修正

- 移除 Logo 的全部探头、点头动效，Logo 保持静止。
- 引导增加跳动指示箭头、点击扩散波纹、步骤进度弹入与成功短线迸发，保持减少动态效果支持。
- 个性化卡片入口支持普通 div/span；需要时展开更多设置。更新此场景的展示记录版本，避免旧记录跳过修复后的引导。
- 修正首页引导文案的蓝粉按钮对应关系。

## 引导完成庆祝

- 恢复 8.2.0 引导，撤下 8.2.1 信息搬运方案。
- 仅在视频库引导中确认“填入”成功后显示“恭喜，视频已填入！”，撒花一次，1.8 秒后收起，也可点“知道啦”；其他阶段结束直接关闭。
- 跳过、关闭和 Esc 不播放庆祝；减少动态效果模式仅显示静态祝贺。

## 个性化卡片内引导恢复

- 关联编辑器引导使用新记录版本，不受旧版已展示标记影响。
- 主页面重新开始引导时递增共享重置序号，iframe 会清除自己的会话和页面去重标记，恢复关联视频标签与添加入口引导。
- 关联输入框出现后再衔接视频库，仍仅在视频填入成功后庆祝。
- 编辑器状态回归和本地浏览器交互检查通过；真实 B 站编辑器需刷新后体验。
