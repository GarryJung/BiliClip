# BiliClip 喵贴 7.2.3 存档

存档日期：2026-11-17。

此版本为用户已确认可用的粘贴修复版，位于新增上传简介菜单功能之前。从当前源码移除 7.3.0 新增部分恢复并单独保存，未覆盖当前主脚本。

- 支持 Ctrl+V、⌘+V 和鼠标右键粘贴。
- 从关联视频的 BV 框或描述文案框粘贴，分别填入 BV 和标题。
- 清空后再次粘贴仍填充两个字段。
- 处理输入框重新渲染，保留配对信息供重复填充。
- 不包含 7.3.0 的上传简介菜单、标题抄录和第二行预设功能。

脚本文件：`biliclip-7.2.3.user.js`。回退时用此文件完整替换当前油猴脚本，保存并刷新页面；避免同时启用两个版本。
